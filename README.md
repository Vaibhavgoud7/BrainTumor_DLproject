# BrainTumor_DLproject
# 🧠 Brain Tumor Detection Using VGG16 (Transfer Learning)

A deep learning–based **Brain Tumor Detection System** that classifies MRI brain images using a **VGG16 Convolutional Neural Network with Transfer Learning**.  

---

## 🚀 Project Objective

Early and accurate detection of brain tumors is critical for effective treatment.  
This project automates tumor classification from MRI images using **deep learning**, reducing dependency on manual diagnosis and enabling faster decision-making.

---

## 🧠 Model Architecture

- **Base Model:** VGG16 (Pre-trained on ImageNet)
- **Approach:** Transfer Learning
- **Custom Layers:** Fully connected CNN layers
- **Input Image Size:** 128 × 128 × 3
- **Output Classes:** 4
- **Loss Function:** Categorical Crossentropy
- **Optimizer:** Adam
- **Framework:** TensorFlow / Keras

---

## 🧪 Tumor Classes

| Class Label | Description |
|------------|------------|
| Glioma | Glioma Tumor |
| Meningioma | Meningioma Tumor |
| Pituitary | Pituitary Tumor |
| No Tumor | Healthy Brain |
